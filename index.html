6.1

Tooltip 信息提示

用悬停交互把“概览”与“细节”放在同一张图中。

为什么需要 Tooltip？

散点图适合比较整体分布，但把每个学生的所有字段都写在图上会造成视觉拥挤。Tooltip 让信息“按需出现”。

交互流程

pointerenter 显示 → pointermove 跟随 → pointerleave 隐藏，同时高亮当前数据点。

⭐ 关键点

Tooltip 不应遮挡鼠标目标；位置要考虑视口边缘；内容只放与当前任务有关的字段。

// 数据绑定 + hover
points.on('pointerenter', (event, d) => {
  tooltip.classed('show', true)
    .html(`<b>${d.id}</b><br>成绩 ${d.score}`);
  d3.select(event.currentTarget).attr('r', 7);
})
.on('pointermove', moveTooltip)
.on('pointerleave', (event) => {
  tooltip.classed('show', false);
  d3.select(event.currentTarget).attr('r', 4.5);
});

6.2

筛选与动态更新

把交互控件变成数据查询条件，并用 transition 保持变化连续。

Filter = 交互式查询

用户选择专业或年级后，程序先过滤数据，再重新聚合。图形只负责表达当前结果。

Data Join

D3 的 selection.data() 将新数据与已有元素匹配；join() 负责进入、更新和退出三种状态。

⭐ 关键点

动态更新时不要清空整个 SVG 重画。保留元素并 transition，用户才能理解“什么发生了变化”。

const filtered = data.filter(d =>
  (major === '全部' || d.major === major) &&
  (grade === '全部' || d.grade === grade)
);

bars.data(summary, d => d.major)
  .join('rect')
  .transition().duration(500)
  .attr('y', d => y(d.avg))
  .attr('height', d => innerH - y(d.avg));
6.3

Brush 区域选择

用拖拽框选一批数据，让“看分布”变成“选群体”。

Brush 做什么？

Brush 把屏幕上的矩形范围转换成数据选择。它常用于散点图探索、区间过滤和联动分析。

屏幕坐标与数据坐标

Brush 返回像素范围，判断点是否落入矩形时使用 x(d) 与 y(d) 投影后的像素位置。

⭐ 关键点

被选中与未选中数据要有明显视觉层级，但不要让未选中数据完全消失，否则会失去上下文。

const brush = d3.brush()
  .extent([[0, 0], [innerW, innerH]])
  .on('brush end', ({selection}) => {
    const selected = selection
      ? data.filter(d => inside(selection, x(d.study_hours), y(d.sleep_hours)))
      : data;
    updateSelection(selected);
  });

6.4

Zoom 缩放与平移

当时间轴太长时，让用户改变观察尺度，而不是把所有细节挤在一起。

Zoom 的本质

不是修改原始数据，而是改变“数据坐标 → 屏幕坐标”的映射。D3 用 transform 记录缩放比例与平移量。

rescaleX

event.transform.rescaleX(x0) 根据当前 transform 生成新的时间比例尺，再重绘坐标轴和折线。

⭐ 关键点

限制缩放倍数，提供“双击重置”，并避免纵向滚动页面时误触图表缩放。

const zoom = d3.zoom()
  .scaleExtent([1, 12])
  .translateExtent([[0, 0], [innerW, innerH]])
  .on('zoom', (event) => {
    const zx = event.transform.rescaleX(x0);
    xAxis.call(d3.axisBottom(zx));
    line.attr('d', d3.line().x(d => zx(d.date)).y(d => y(d.value))(series));
  });

6.5

多视图联动 Dashboard

把前四节的思想组合起来：一个选择，同时改变多个视图。

Linked Views

不同图表共享同一个选择状态。散点图负责定位个体，条形图负责比较类别，统计卡片负责给出精确数值。

一个状态，多种表达

本例用 selectedMajor 保存专业筛选，所有视图都从同一份 filteredData 派生，避免多个图表状态不一致。

⭐ 关键点

联动不是“图越多越好”。每个视图必须回答不同问题，并且共享明确的交互语义。

let selectedMajor = '全部';

function updateDashboard() {
  const filtered = selectedMajor === '全部'
    ? data
    : data.filter(d => d.major === selectedMajor);

  updateScatter(filtered);
  updateGradeBars(filtered);
  updateStats(filtered);
}
