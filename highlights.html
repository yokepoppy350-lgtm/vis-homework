01 / 项目目标 · Project goal

本网站围绕“如何做好页面布局”展开，重点解释设计决策的原因，再以 HTML、CSS 和 JavaScript 展示实现与变化。用户逐步改进同一个学习数据看板，完成信息分区、间距、局部对齐、整体网格、响应式和综合评估。

The website teaches how to make effective page-layout decisions, explains the reasoning, and demonstrates implementation with HTML, CSS and JavaScript. Learners progressively improve one learning dashboard through information structure, spacing, local alignment, grids, responsiveness and final review.

02 / 六节案例课程 · Six case-based lessons

章节 / Lesson理论与操作 / Principles and interaction

03 / 教学亮点 · Teaching highlights

讲解 → 关键代码 → 动态演示

每节都有任务、四项理论解释和设计原则。关键代码随实验参数更新，学生可以观察操作与布局变化之间的关系，而不是只记忆属性。改进前的画面明确标为教学反例，避免误用。

Each lesson provides a task, four explanations and a design principle. Key code updates with experiment parameters so learners connect actions to layout changes instead of memorizing properties. The “Before” view is explicitly marked as a counterexample.

双语共享结构与交互 / Shared bilingual structure and interaction

中文与英文讲解逐段配对。导航、任务、控件、动态反馈和预览内容均有对应语言。切换语言保留当前章节、标签页和参数；语言选择保存在浏览器中。

Chinese and English explanations are paired paragraph by paragraph. Navigation, tasks, controls, feedback and preview content are localized. Switching language preserves the lesson, tab and parameters; the browser remembers the language choice.

04 / 实现亮点 · Implementation highlights

保留原版的侧边目录、单小节阅读器与三标签结构，增强字号、留白与键盘焦点。演示放在独立 iframe 中，避免外层教学页面的样式干扰。响应式实验以 520px、760px 为统一断点，代码和运行预览共用规则。盒模型反馈基于实际元素尺寸，网格辅助线使用相同列模板和间距。

The original sidebar, single-lesson reader and three-tab structure are retained, with improved typography, spacing and keyboard focus. An independent iframe isolates demos from host-page styles. The responsive experiment shares 520px and 760px rules between the code and preview. Box-model feedback measures actual dimensions; grid guides share the same tracks and gaps.

项目没有外部字体、在线图表服务或构建依赖，可直接打开入口文件。图表使用内置模拟内容，页面布局是教学重点。

No external fonts, online chart services or build dependencies are required. Open the entry file directly. Charts use built-in simulated content because page layout is the teaching focus.

独立演示与讲义 · Standalone demos and notes

参考老师课程的组织方式，每节增加“为什么这么写”和“常见错误”。演示可独立打开，适合课堂展示；完整中英文讲义可从页面底部下载。

Following the sample course structure, each lesson includes reasoning and common pitfalls. Demos can open independently for classroom display, and complete lecture notes in both languages are downloadable from the footer.

结构参考：老师课程门户 / Teacher’s course portal。本项目为页面布局作业章节。This project is a page-layout assignment chapter.

05 / 使用与提交 · Use and submission

解压源码包，打开 index.html。发布时，将源码包内部文件放入静态网站的发布目录，确保 index.html 位于该目录根部。发布后以无登录窗口检查双语、六节演示和手机布局，再提交实际可访问的网页地址。

Extract the source archive and open index.html. To publish, place its contents in a static website’s publishing folder, with index.html at that folder’s root. Check both languages, all six demos and phone layouts without signing in, then submit the working URL.
