# 第 6 章：可视化页面布局

课程作业章节，延续原课程网站“讲解 / 关键代码 / 演示”的教学结构，主题调整为网页页面布局。

## 章节内容

1. 页面骨架与视觉层级
2. 盒模型与间距系统
3. Flexbox：一维弹性布局
4. CSS Grid：二维网格布局
5. 响应式布局
6. 综合案例：可视化 Dashboard 布局

每一节都包含独立、可操作的 Demo。

## 技术

- HTML5
- CSS3
- 原生 JavaScript
- 无构建工具、无 npm 依赖
- 可直接部署到 GitHub Pages

## 本地打开

可以直接打开 `index.html`。若浏览器环境限制本地脚本，可在项目目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。
